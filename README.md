# Projeto: Lista de Tarefas em Python

Meu primeiro projeto em Python! Um programa que roda no terminal para gerenciar tarefas.

## O que faz
- Adiciona tarefas
- Mostra todas as tarefas
- Remove tarefas
- Menu simples

## Como usar
1. Tenha Python instalado
2. Baixe o arquivo main.py
3. No terminal: python main.py

## O que aprendi
- Como usar listas em Python
- Como fazer menus com while e if
- Como o input e print funcionam
- Básico de Git e GitHub
